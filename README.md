# Кредиты для бизнеса

Адаптивный интерактивный прототип на Angular 19 и TUI.

[Открыть сайт](https://e-dryaneva.github.io/credit-business/)

## Исходники

Полный исходный проект, оригинальные ассеты и локальная дизайн-система находятся в `credit-business-source.zip`. Архив содержит обычные папки `src` и `vendor`, конфигурацию и lock-файл зависимостей.

Для локального запуска распакуйте архив в отдельную папку, установите Node.js 22 и выполните:

```sh
npm ci
npm start
```

Локальный адрес: http://127.0.0.1:4212/. Подробное описание сценариев находится в README внутри архива. Демо-код подтверждения: `1234`. Банковский API не подключён.

## Публикация

GitHub Actions распаковывает исходники, выполняет `npm ci` и `npm run build:pages`, затем публикует `dist/browser` в GitHub Pages. Workflow имеет только чтение содержимого репозитория и права публикации Pages. Он не изменяет исходники.

Для обновления замените ZIP и его SHA-256 в `.github/workflows/pages.yml`.
